# Parking Occupancy

A browser-based computer vision system for vehicle detection, tracking,
traffic analysis, speed estimation, and parking occupancy analysis.

## Project Status

🚧 Phase 1 — Working Chrome Extension

- [ ] Phase 6 — Evaluation

## Technology

- JavaScript
- HTML
- CSS
- Chrome Extensions Manifest V3
- TensorFlow.js
- COCO-SSD
- Computer Vision

## Current Objective

Develop a Chrome extension capable of processing locally uploaded
videos for vehicle detection, traffic analysis, and parking occupancy
analysis directly in the browser.
